# 장날 가자 (Jangnal Gaja) 🏪

전국 전통시장 정보를 확인하고, 오늘 열리는 장날을 알려주는 안드로이드 앱입니다.

## ✨ 주요 기능

### 📅 스마트 장날 안내
* **오늘의 장**: 오늘 날짜를 기준으로 열리는 시장을 자동으로 필터링
* **다음 장날 표시**: 각 시장의 다음 개장일과 남은 일수를 실시간으로 계산
* **정확한 주기 계산**: 3일장, 4일장, 5일장, 6일장, 7일장 등 다양한 주기 지원

### 🗺️ 지도 기능
* **카카오맵 연동**: 전국 시장 위치를 지도에서 한눈에 확인
* **마커 클릭**: 지도에서 시장 마커를 클릭하여 상세 정보 확인
* **길찾기**: 지도 앱(네이버 지도, 카카오맵, 구글맵 등)과 연동

### 📋 상세 정보
* **시장 유형**: 상설시장, 3일장, 4일장, 5일장 등 명확한 구분
* **개장 일정**: 
  - 시작일 (예: "매월 1일부터")
  - 주기 (예: "5일마다")
  - 이번 달 장날 전체 목록
  - 다음 장날 및 D-day
* **위치 정보**: 도로명 주소 및 좌표
* **주요 품목**: 각 시장의 특산물 및 취급 품목
* **연락처**: 시장 관리 사무소 전화번호

## 🚀 빌드 및 실행

### 1. 프로젝트 열기
```bash
Android Studio에서 프로젝트 열기
File > Open > 프로젝트 폴더 선택
```

### 2. 카카오맵 API 설정 (필수!)
지도 기능을 사용하려면 카카오 개발자 사이트에서 API 키를 발급받아야 합니다.

**자세한 설정 방법**: [KAKAO_MAP_GUIDE.md](KAKAO_MAP_GUIDE.md) 참조

간단 요약:
1. [카카오 개발자 사이트](https://developers.kakao.com/)에서 앱 생성
2. Android 플랫폼 등록 (패키지명: `com.jangnal.gaja`)
3. 키 해시 등록
4. 네이티브 앱 키를 `AndroidManifest.xml`에 입력

### 3. Gradle Sync 및 빌드
```bash
1. Sync Project with Gradle Files
2. Build > Make Project
```

### 4. 실행
```bash
에뮬레이터 또는 실기기 연결 후 Run (Shift+F10)
```

## 📱 화면 구성

### 1. 목록 화면
* **오늘의 시장**: 오늘 개장하는 시장만 필터링
* **전체 시장**: 모든 시장 목록
* 각 시장 카드에 표시되는 정보:
  - 시장 이름
  - 시장 유형 (예: "5일장 (1일부터)")
  - 다음 장날 또는 "오늘 장날!" 표시

* 위치 및 연락처
* 주요 품목
* 길찾기 버튼

### 3. 지도 화면

* 시장 위치 마커 표시 (최대 500개)

* 로딩 및 에러 상태 표시
